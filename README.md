# AD User Onboarding & Offboarding

PowerShell scripts to automate creating and disabling Active Directory
user accounts from a CSV file.

## Planned features
- Bulk user creation from CSV
- Department-based OU placement and group assignment
- Logging and error handling
- Matching offboarding script
- Mailbox setup (Microsoft 365 / Exchange)

## Status
In progress. Lab environment not built yet.
